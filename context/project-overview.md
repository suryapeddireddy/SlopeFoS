# SlopeFoS — Project Overview

## Overview
SlopeFoS is a web-based geotechnical engineering tool designed to calculate the Factor of Safety (FoS) for open-pit mine slopes using Limit Equilibrium Methods (LEM), specifically the Ordinary Method of Slices and Bishop's Simplified Method.

## Key Features
1. **Parameter Input**: Custom inputs for slope geometry (height, face angle), soil/rock properties (cohesion $c'$, friction angle $\phi'$, unit weight $\gamma$), and pore water pressure / water table.
2. **Method of Slices Engine**: Automated division of a circular trial failure arc into vertical slices to compute driving versus resisting forces.
3. **FoS Evaluation**: Instant computation of Factor of Safety with standard geotechnical thresholds ($FoS < 1.0$ unstable, $1.0 - 1.3$ marginal, $> 1.3$ stable).
4. **Visual Cross-Section**: Clean graphical rendering of the slope profile and trial slip surface.
